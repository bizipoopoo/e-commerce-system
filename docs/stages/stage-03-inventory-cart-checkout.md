# Stage 03：库存、购物车与结算预览

## 范围

- SKU 库存、预警阈值、库存流水
- 管理员库存查询与调整
- 基于条件更新的库存预占和释放，防止超卖
- 用户购物车增删改、勾选和失效状态
- 结算预览、运费与应付金额计算
- 商城商品快捷加购、购物车抽屉和结算预览

## 非目标

- 正式订单、库存确认扣减和订单超时释放调度
- 优惠券、满减、会员价
- 多仓库存和仓库调拨
- 真实运费模板与地址区域计费

## 核心规则

1. 可售库存等于总库存减去预占库存。
2. 库存预占必须使用数据库条件更新，不能先查后改。
3. 同一业务键的预占请求保持幂等。
4. 购物车单个 SKU 数量范围为 1–99，且不能超过当前可售库存。
5. 结算预览只处理已勾选商品，并再次校验商品状态、价格和库存。
6. 商品金额满 ¥299 免运费，否则收取 ¥15 演示运费。

## 验收条件

1. 登录用户可以完成加购、修改数量、勾选和删除。
2. 库存不足时加购和结算返回明确错误。
3. 管理员可以调整库存，普通用户不能访问库存管理接口。
4. 结算预览金额计算正确，并返回每一项商品快照。
5. 商城购物袋数量、商品列表和结算金额均来自真实 API。
6. 库存预占的原子更新和幂等行为有自动化测试。
7. Stage 03 Review 的 P0/P1 清零并推送 GitHub。
