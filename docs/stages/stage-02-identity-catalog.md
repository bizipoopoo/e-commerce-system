# Stage 02：身份、商品与首页数据化

## 范围

- 邮箱注册、登录、JWT 鉴权和当前用户信息
- 类目、品牌、商品、SKU 与首页 Banner 的第一版数据模型
- 商品列表、搜索、详情、首页聚合 API
- 管理员商品创建、编辑与上下架 API
- 商城首页从真实 API 加载商品和类目
- 商城登录注册交互与会话保存

## 非目标

- 手机短信、第三方登录、找回密码
- 复杂商品属性模板和多媒体管理
- Elasticsearch 搜索
- 库存锁定、购物车与下单

## 验收条件

1. 新用户可注册、登录并使用 JWT 获取个人信息。
2. 重复邮箱、错误密码和受保护接口返回明确错误。
3. 首页、类目、商品列表和详情均由数据库数据驱动。
4. 管理员可创建、编辑和上下架商品，普通用户无权操作。
5. 商城在后端可用时展示真实数据，失败时提供明确错误反馈。
6. 后端集成测试、模块边界测试和两个 Web 生产构建通过。
7. Stage 02 Review 的 P0/P1 清零并推送 GitHub。
