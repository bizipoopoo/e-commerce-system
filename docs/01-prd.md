# Aurora Commerce 产品需求文档

## 1. 产品目标

在一周内交付一套视觉完整、功能覆盖全面、核心交易链路真实可用的 Web 电商 Demo，并保留升级为正式产品和拆分微服务的架构空间。

成功标准：

1. 用户能够完成注册登录、浏览检索、加购、结算、支付、履约和售后闭环。
2. 运营人员能够管理商品、库存、订单、内容、营销和消息推送。
3. 首页、商品详情、交易页面和运营后台具备统一且精致的视觉体验。
4. 推荐流和消息推送具备可解释、可配置、可现场演示的数据链路。
5. 核心业务具备状态机、事务、幂等校验和自动化测试。

## 2. 用户角色

| 角色 | 核心诉求 |
|---|---|
| 游客 | 浏览商品、搜索、查看活动与内容 |
| 注册用户 | 收藏、加购、下单、支付、评价、售后、接收消息 |
| 运营人员 | 管理商品、内容、营销活动与用户反馈 |
| 仓储/客服 | 处理库存、发货、退款退货和咨询 |
| 管理员 | 权限、配置、审计与数据看板 |

## 3. 用户端功能

### 3.1 账户与会员

- 手机号或邮箱注册、登录、退出与令牌刷新
- 用户资料、头像、收货地址、默认地址
- 会员等级、成长值和账号安全信息展示
- 登录保护、权限控制和敏感操作审计

### 3.2 商品与搜索

- 多级类目、品牌、SPU、SKU、规格属性和媒体图集
- 商品上下架、价格、活动标签和库存状态
- 关键词、类目、品牌、价格区间筛选
- 综合、销量、价格和上新排序
- 搜索建议、热搜、搜索历史和无结果推荐

### 3.3 交易履约

- 购物车增删改、勾选、失效商品和实时金额汇总
- 结算确认、地址选择、优惠券、配送方式和订单备注
- 下单库存校验、价格快照、优惠分摊和防重复提交
- 模拟支付、支付回调、支付记录与支付结果
- 订单列表、详情、取消、超时关闭、确认收货
- 模拟发货和物流轨迹
- 退款、退货申请、审核结果与售后进度

### 3.4 营销互动

- 优惠券领取与使用、满减活动、限时促销
- 收藏夹、浏览足迹、商品评价、晒单和点赞
- 首页 Banner、频道金刚区、专题页、内容文章
- 热销榜、新品、猜你喜欢和相似商品

### 3.5 信息流与消息

- 记录曝光、点击、搜索、收藏、加购和购买行为
- 基于类目偏好、热度和运营位生成可解释推荐流
- 订单、支付、物流、售后、营销和系统消息
- 站内消息中心、未读数和 SSE 实时通知

## 4. 运营端功能

- 数据看板：GMV、订单数、客单价、用户数、转化趋势、热销商品
- 商品中心：类目、品牌、SPU、SKU、属性、图片与上下架
- 库存中心：库存调整、预警、库存流水和批量操作
- 订单中心：查询、发货、取消、备注和售后处理
- 用户中心：用户资料、状态、等级和行为概览
- 营销中心：优惠券、活动、推荐位和 Banner
- 内容中心：专题、文章、频道内容和发布计划
- 消息中心：消息模板、人群选择、定时发布和效果统计
- 评价管理：查看、回复、隐藏和敏感内容处理
- 系统管理：角色权限、配置、操作日志

## 5. 核心业务规则

### 5.1 订单状态

```text
PENDING_PAYMENT -> PAID -> SHIPPED -> COMPLETED
       |             |         |
       +-> CLOSED    +-> REFUNDING -> REFUNDED
```

- 创建订单时保存商品名称、SKU、单价和优惠的不可变快照。
- 支付回调必须以支付流水号作为幂等依据。
- 未支付订单超时关闭并释放预占库存。
- 已发货订单不能直接取消，只能进入售后流程。

### 5.2 库存

- 可售库存 = 实际库存 - 锁定库存。
- 下单锁定库存，支付成功确认扣减，取消或超时释放。
- 更新必须带版本号或条件更新，防止超卖。

### 5.3 推荐

- 未登录用户：运营推荐 + 全站热度。
- 新用户：类目热度 + 新品。
- 活跃用户：最近行为类目权重 + 热度修正 + 已购降权。
- 推荐项返回 `reason`，用于页面解释和演示。

## 6. 页面地图

用户端：登录注册、首页、分类、搜索、商品详情、购物车、结算台、收银台、支付结果、订单列表、订单详情、售后、收藏、足迹、优惠券、发现频道、消息中心、个人中心、地址管理。

运营端：登录、数据看板、商品、类目品牌、库存、订单、售后、用户、优惠券活动、推荐位、内容、消息推送、评价、权限与审计。

## 7. 非功能需求

- 桌面端优先，适配 1280px 及以上常用分辨率。
- 普通查询接口目标响应时间小于 500ms。
- API 统一错误结构，关键写操作携带请求幂等键。
- 密码不可明文存储，管理端接口强制鉴权。
- 数据库变更统一通过 Flyway 管理。
- 核心流程提供单元测试和集成测试。
- 提供初始化演示数据和一键启动说明。
