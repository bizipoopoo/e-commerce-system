# 一周交付计划

| 日期 | 目标 | 可验收产物 |
|---|---|---|
| Day 1 | 需求、架构、模型和工程基线 | PRD、架构图、ER、前后端可启动骨架 |
| Day 2 | 用户、商品与首页 | 登录、商品管理、类目搜索、精致首页 |
| Day 3 | 库存、购物车与结算 | SKU、库存防超卖、购物车、结算预览 |
| Day 4 | 订单、支付与履约 | 下单、状态机、模拟支付、发货物流 |
| Day 5 | 营销、内容、推荐与消息 | 优惠券、专题、推荐流、SSE 消息 |
| Day 6 | 售后、运营后台与测试 | 售后闭环、看板、集成测试、Code Review |
| Day 7 | 联调、部署与演示 | 演示数据、部署说明、演示脚本、回归报告 |

## 研发质量门禁

- 每个用例先对应 PRD 验收条件，再实现 API 和页面。
- 所有数据库变更必须有 Flyway migration。
- 核心领域规则必须有测试，提交前运行后端测试和前端构建。
- 每天对 Git Diff 做一次 AI Code Review，并记录发现和修复结果。
- 演示功能不得只有菜单占位，至少具备完整 UI 状态和可解释数据。
